# dsh-compressor

*上下文最多能少两成。模型该怎么答还怎么答，已经发出去的前缀也不改。*

[![npm](https://img.shields.io/npm/v/dsh-compressor.svg)](https://www.npmjs.com/package/dsh-compressor)

包在 [npm](https://www.npmjs.com/package/dsh-compressor)。用官方命令装进 profile（内部是 pnpm）：

```bash
dsh plugin --profile web add dsh-compressor
```

不要 `npm i -g`。说明见[仓库中文 README](https://github.com/lifeodyssey/dsh-compressor/blob/main/README.zh-CN.md)。
